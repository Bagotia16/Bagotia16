# Deepanshu Bagotia - Personal Portfolio & Blog

Welcome to the repository for my personal website! This project serves as a digital record of my work, ideas, and experiences at the intersection of Machine Learning, Neuroscience, and Startups.

## 🌐 Overview

This is a static website built to showcase my professional journey, research papers, patents, and technical blogs. It features a clean, editorial-style design with a unique interactive timeline for the resume section.

**Live Site:** [Deepanshu Bagotia's Website](https://bagotia16.github.io/Bagotia16)

## ✨ Features

- **Editorial Aesthetics:** Typography-driven design using *Newsreader* for headings and *JetBrains Mono* for technical details, paired with a warm cream and dark color palette.
- **Interactive Resume Timeline:** A custom-built, responsive timeline that visualizes education, experience, papers, and patents. It includes dynamic tenure lines that scale based on duration and interactive year-based navigation.
- **Blog Section:** A filterable grid of articles categorized by topics like ML, Brain, and Startups, linking to full articles on Medium.
- **Fully Responsive:** Optimized for both desktop and mobile viewing, built on top of Bootstrap.

## 🛠️ Technology Stack

- **HTML5:** Semantic structure and content.
- **CSS3:** Custom styling, animations, and responsive layouts.
- **JavaScript:** Custom logic for the interactive resume timeline, intersection observers for scroll animations, and dynamic filtering.
- **Libraries/Frameworks:**
  - [Bootstrap 4](https://getbootstrap.com/docs/4.0/) (Grid and components)
  - [jQuery](https://jquery.com/) (DOM manipulation and vendor plugins)
  - [Animate.css](https://animate.style/) (Animations)
- **Typography & Icons:** Google Fonts (Newsreader, JetBrains Mono, Nunito Sans) and FontAwesome.

## 🚀 How to Run Locally

Since this is a static website with no complex backend, running it is very straightforward:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bagotia16/Bagotia16.git
   cd Bagotia16
   ```

2. **Open in Browser:**
   Simply open the `index.html` file in your preferred web browser.
   *Or*

3. **Run a Local Server (Recommended):**
   To ensure all assets and scripts load correctly (especially modules or fetching local files), serve the directory using a simple local server. For example, using Python:
   ```bash
   python3 -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
